# 性別(gender)属性 設計ドキュメント v2

作成: 2026-07-13 / 対象: mobile_order-app (prod: mobile-order-prod / store_ar2y9, Firestore named DB `main`)

## 1. 背景・目的

Shopify下書きに性別タグ(MEN/WOMEN)を自動付与したい（UNISEXは MEN+WOMEN+UNISEX）。さらに Amazon/楽天/BASE/STORES でも性別を使える単一の正データにしたい。
→ 性別を **商品の属性 `products.gender`**（チャンネル非依存の正データ）に集約し、その**入力方法を分類ノードごとに設定できる**ようにする。

## 2. 現状の問題

性別が分類ツリーに二重に埋め込まれている（有効商品 31,731件）:

| 性別ソース | 実データ | 件数 |
|---|---|---|
| カテゴリーグループ（アパレル） | `categoryGroupName`=MEN/WOMEN/UNISEX | MEN 9,847 / WOMEN 1,980 / UNISEX 0 |
| 末端サブカテゴリー（眼鏡・雑貨バッグ） | `subCategoryName`=MEN/WOMEN/UNISEX | MEN 122 / WOMEN 676 / UNISEX 5,947 |
| 性別なし（食品・雑貨等） | — | 13,159 |

サブカテ枠が1つのため眼鏡は性別に転用し、性別サブカテが **MEN×6/WOMEN×6/UNISEX×6=18個** 複製されている。

## 3. 提案モデル（分類ノード単位の性別設定）

### 3.1 各分類ノードに「ジェンダーオプション」を設定できる
カテゴリーグループ / カテゴリー / サブカテゴリー の**新規作成・編集**に「ジェンダーオプション」ボタンを追加。押すと、そのノードの性別動作を2モードから選ぶ:

- **固定 (fixed)**: MEN / WOMEN / UNISEX のいずれかを選ぶ → そのノードに属する商品は自動でその性別。
- **選択 (select)**: 商品マスターでその分類を選ぶと**性別セレクタが表示**され、商品ごとに選ぶ。未選択は UNISEX 扱い。

ノードは性別設定「なし」も可（従来通り性別に関与しない）。

### 3.2 商品の性別解決（優先順位＝子が勝つ）
商品の分類（グループ→カテゴリー→サブカテゴリー）のうち、**最も末端側で性別設定を持つノード**が支配する:

```
サブカテゴリーの設定 > カテゴリーの設定 > カテゴリーグループの設定 > なし
```

- 支配ノードが **固定** → `products.gender` = その固定値（自動、UIは読み取り表示）。
- 支配ノードが **選択** → 商品マスターで選んだ値（未選択=UNISEX）。
- どのノードにも設定が無い → `products.gender=''`（性別なし）。

> 例: 「固定=MEN」のカテゴリーグループの中に「選択」のカテゴリーを作ると、そのカテゴリーの商品は**選択が優先**（グループの固定MENを上書き）。

### 3.3 具体例（今回のデータ）
- **カテゴリーグループ MEN** → ジェンダーオプション=固定・MEN。商品登録では性別は自動でMEN、Shopifyに `MEN` タグ。
- **眼鏡カテゴリー（フレーム等）** → ジェンダーオプション=選択。商品登録で眼鏡に進むと**性別セレクタ**が出る。未選択=UNISEX（→ MEN/WOMEN/UNISEX タグ）。
  - 眼鏡の現在のサブカテ枠（性別に転用中／「サブカテゴリーなし」表示）は、**性別セレクタに置き換え表示**する。

## 4. データモデル

分類3コレクション（`productCategoryGroups` / `productCategories` / `productSubCategories`）に追加:
```
genderMode: 'fixed' | 'select' | ''      // ''=性別設定なし
genderFixedValue: 'MEN' | 'WOMEN' | 'UNISEX' | ''   // genderMode='fixed' のときのみ
```

商品 `products` に追加:
```
gender: 'MEN' | 'WOMEN' | 'UNISEX' | ''   // 解決済みの正データ（大文字）
```
- 表記は **大文字**（現データ・Shopify既存タグに合わせる）。
- 既存の categoryGroup/category/subCategory は商品タイプ(分類)専用へ戻す。

## 5. UI

### 5.1 分類マスター（グループ/カテゴリー/サブカテの作成・編集）
- 「ジェンダーオプション」ボタン → モーダル/インライン:
  - モード: なし / 固定 / 選択
  - 固定時: MEN・WOMEN・UNISEX を選択

### 5.2 商品マスター（分類選択＝ProductClassificationControl）
- 分類を選ぶたびに支配ノードの性別設定を解決:
  - 固定 → 性別は自動表示（読み取り）。
  - 選択 → **性別セレクタ**（未設定/メンズ/レディース/ユニセックス、既定=ユニセックス）を**追加表示**（サブカテ枠とは併存）。
  - なし → 性別UIなし。
- **サブカテ枠**: サブカテが無ければ非表示（「サブカテゴリーなし」は出さない）。性別セレクタはサブカテの有無と独立に、選択モード時に追加表示。

### 5.3 性別はグループ単位
性別は **商品グループ（＝Shopify商品1つ）につき1つ**。同じグループ（同名の全サイズ/色）は同一性別。性別をまたぐ商品は **無理に分割せず UNISEX** にして1グループのまま MEN・WOMEN 両方に露出する（分割すると単一サイズだけ別SKU＝別Shopify商品になり断片化するため避ける）。混在した場合の代表値は primary 商品の gender。

## 6. Shopify マッピング（タグ）

`products.gender` → タグ:
- `MEN` → `MEN`
- `WOMEN` → `WOMEN`
- `UNISEX` → `MEN` + `WOMEN` + `UNISEX`
- `''` → 性別タグなし

商品タイプ(productType)は従来通り（アパレル=categoryGroupName / その他=categoryGroupName or categoryName）。タグ生成は `buildShopifyProductSetInput`/`buildShopifyProductUpdateInput` を gender 参照へ差し替え。

## 7. 他チャンネル（将来）

| チャンネル | MEN | WOMEN | UNISEX |
|---|---|---|---|
| Amazon | mens | womens | unisex-adult |
| 楽天 | メンズ | レディース | 男女兼用 |
| BASE/STORES | タグMEN | WOMEN | MEN+WOMEN(+UNISEX) |

各連携は `products.gender` を読むだけ。分類ツリーに依存しない。

## 8. 移行手順（段階）

**Phase 1: フィールド追加＋設定＋バックフィル（読み取り統一・低リスク）**
1. 分類ノードに genderMode/genderFixedValue を付与:
   - カテゴリーグループ MEN/WOMEN/UNISEX → fixed（同値）
   - 眼鏡カテゴリー（フレーム/サングラス/時計/その他BASIC）・生活雑貨（財布・マネークリップ/ハンドバッグ）→ select
2. `products.gender` バックフィル（31,731件）:
   - 支配ノードが fixed → 固定値（アパレル 11,827件）
   - 支配ノードが select → 旧サブカテの性別値（MEN/WOMEN/UNISEX）、無ければ UNISEX（眼鏡・バッグ 6,745件）
   - それ以外 → ''（13,159件）
3. Shopifyタグ生成を gender 参照へ（dev→prod）。
   → 読み取りは一本化。UI/タクソノミーはまだ触らず検証可能。

**Phase 2: UI＋タクソノミー整理**
1. 分類マスターに「ジェンダーオプション」UI、商品マスターに性別セレクタを実装。
2. 眼鏡・バッグ配下の商品のサブカテを本来の商品タイプ or 空へ付け替え、性別サブカテ18個を削除（参照0確認後）。

**Phase 3（任意・将来）: アパレルのグループ再編**
- MEN/WOMEN グループを商品タイプ主体へ。売り場再編を伴うため当面送り（Phase1/2で運用可能）。

## 9. 確定事項（ユーザー合意 2026-07-13）
1. 表記は **大文字**（MEN/WOMEN/UNISEX）。
2. アパレルは categoryGroup=固定で **自動反映を併用**（Phase3送り可）。
3. 固定グループ内に選択カテゴリーを作った場合、**選択（子）が優先**。
4. UNISEX のタグは **MEN + WOMEN + UNISEX の3つ**。
5. 未選択（選択モードで空）は **UNISEX 扱い**。

## 10. 残論点の確定（2026-07-13）
- **サブカテ枠**: 併存。サブカテ無しは非表示（「サブカテゴリーなし」を出さない）、性別セレクタは選択モード時に追加表示。将来の本来サブカテとも両立。
- **グループ単位**: 性別はグループ（=Shopify商品）単位で1つ。性別またぎは UNISEX にして1グループ維持（分割しない）。混在時の代表は primary 商品の gender。
