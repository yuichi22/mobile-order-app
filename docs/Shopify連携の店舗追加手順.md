# Shopify 連携の店舗追加手順

POS（mobile-order-app）の店舗を Shopify ストアにつなぐときの手順。画面は「設定 > POS > EC連携 > Shopify連携設定」。

## 1. Shopify 側で連携アプリを用意する

- Shopify Dev Dashboard でその店用の連携アプリを作り、ストアにインストールする。
- アクセス範囲に `read_inventory`・`write_inventory`・`read_locations` を入れる（商品同期も使うなら商品の権限も）。
- 「設定」のクライアントID・シークレットを控える。**別の店のアプリの鍵を使い回さない。**

## 2. POS の画面で入れる

- Shopifyストアドメイン：`xxxx.myshopify.com` の形（独自ドメインではない）。
- クライアントID・シークレット：手順 1 で控えたもの。シークレットは保存後「設定済み」とだけ表示され、画面からは読めない（サーバーだけが持つ）。
- Shopify Location ID：在庫連携を使うときは必須。Shopify の「設定 > ロケーション」にあるもの。

## 3. 在庫連携を ON にして保存する

- **在庫連携を ON で保存すると、Shopify からの在庫通知（ECで売れた分をレジ在庫へ反映する通知）も自動で登録される。** Shopify 管理画面で Webhook を手で作る必要はない（手で作った通知は署名が合わず使えない）。
- 保存時に「鍵 → 権限 → ロケーション → 通知の登録 → 登録できたかの読み戻し」を順に確かめ、全部通ったときだけ ON になる。どこかで止まったら OFF のまま保存され、理由と直し方が画面に出るので、そのとおり直して保存し直す。
- **保存したら、トグルの下に「Shopify からの通知：有効」と出ていることを画面で確かめる。** 赤い「止まっています」が出たら、書かれている直し方に従う。
- 変更が無いと保存ボタンは出ない。入れ直すときはシークレットを入れ直すと保存ボタンが出る。

## その後

- 毎晩 03:00 に通知が登録されているかを自動で確かめ、外れていれば登録し直す。すでに ON の店舗が自動で OFF になることはない（失敗は画面に赤で出る）。
- 在庫連携を OFF にして保存すると、通知も削除される。
- 開発環境（dev）では Shopify へ通知を登録しない（本番の受け口を dev から登録しない・本番の店舗の通知に触らないため）。
